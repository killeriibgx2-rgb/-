# 2.7.5 — готовая еда в результате

По просьбе владельца готовое мясо теперь остаётся в правом слоте результата.
Удалён serverTick TAIL, который переносил выход обратно во входной слот.
Ванильная логика результата теперь одинакова для еды и остальных рецептов:
проверка места, выдача опыта при извлечении, Shift-клик и воронки.
Надбавка времени на разморозку и текущие правила вставки еды не изменены.
Это заменяет прежнее требование «готовить во входном слоте» из SPEC_FOOD_RU.md.

Уже приготовленный предмет во входе старой печи автоматически не перемещается:
его можно забрать вручную; следующие порции появятся справа.

Ручная проверка (не выполнена в песочнице): сырое/замороженное мясо с топливом,
заполненный выход, Shift-забор результата, опыт и извлечение воронкой.
