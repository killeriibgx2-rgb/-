# GUI печи — 2.7.3

## Реализация

- `CozyFurnaceScreen` наследует ванильный `FurnaceScreen`: книга рецептов,
  подсказки, узкий экран и клавиатурное управление остаются ванильными.
- Сохраняется исходный `FurnaceMenu`, его 39 объектов Slot и их ID.
  Клиентский accessor меняет только координаты. Сервер получает прежние ID.
- Начало предмета = рамка текстуры + 1 пиксель. Никакого вычитания 8.
- Вход (72,27), топливо (72,56), выход (137,44), инвентарь (9,85), хотбар (9,143).
- Выход остаётся видимым и доступным: нужен для руды, старых сохранений и
  предметов, оставленных автоматизацией. Еда готовится во входном слоте по существующей логике.
- Шкала использует ванильный синхронизированный прогресс (24 ступени), угли — остаток топлива.
- Используются реальные размеры PNG 176×166, не стандартный атлас 256×256.
- Замена только обычного ванильного экрана печи и только при включённом
  синхронизированном `enableCookingTweaks`. Коптильня, плавильня и экраны сторонних модов не заменяются.
- Новых пакетов и изменений серверного меню нет. Accessor зарегистрирован только в client mixins.

## Ручная проверка в Minecraft (ещё НЕ выполнена)

1. Открыть печь в одиночной игре и на выделенном сервере: нет ошибки применения accessor.
2. Положить один сырой и замороженный продукт; проверить возврат готового во вход.
3. Переплавить руду; забрать выход обычным кликом и Shift, проверить опыт.
4. Проверить все 36 ячеек, цифры хотбара, перетаскивание, разделение стака и Shift.
5. Открыть книгу рецептов, выбрать рецепт, проверить ghost-слоты и автозаполнение.
6. Изменить GUI scale/размер окна, включая узкий экран с открытой книгой.
7. Проверить угли без топлива, при горении и после остановки; шкалу 0..100%.
8. Отключить cooking tweaks и заново открыть печь — должен быть ванильный экран.
9. Проверить коптильню, плавильню и существующую печь с выходом из старого сохранения.

Известная особенность прежней логики еды: запрет стака в canPlaceItem не является
полной реализацией лимита Slot.getMaxStackSize(1). Это отдельная серверная задача;
данный экран не меняет правила вставки и не заявляет исправление автоматизации.
